## 免备案免掉的是备案流程，不是别的

工信部的备案管的是中国大陆境内的服务器。机器放在香港、美国、欧洲，不在这套流程的管辖范围里，所以买完就能绑域名解析上线，不用等管局审核。这是"免备案"的全部含义。

它没免掉两件事。

一件是机房所在地的法律。境外服务器照样受当地法规约束，违规内容会被封停，这一条在提供免备案机型的商家中口径一致，并非某家的特殊规定。

另一件是"能不能被访问"。网站打不开，通常不是因为它免备案，而是 IP 或域名本身出了问题。反过来也成立：免备案不等于国内访问一定快，快慢取决于机房到国内的线路等级和回程路由，跟要不要备案没有关系。同样标"香港节点"，走 CN2 GIA 或优化 BGP 的机房能把延迟压到几十毫秒，走普通国际线路的廉价共享机可能让页面加载拖到两三秒。有国内备案机厂商的博客就是这么描述 30-40 元/月香港轻量机的，那说的是低端共享线路，不能代表整个香港节点。
